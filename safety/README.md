# Console Mode safety check

Every new MiSTer Linux release and MiSTer Main change is checked against the current Console Mode
automatically, and the verdicts are kept here (copied every hour): `linux_update.ini` and `cores_update.ini`
(safe, warning or unsafe), what each means (`*_readme.ini`), the facts checked (`cm_watch.json`) and the full
report (`cm_report.md`). Console Mode for Windows shows them in Update All, next to the Linux guard.
