# Console Mode for Windows

The PC app for Console Mode on the SuperStation One: box art and game details, Update All with restore points,
power, memory cards, the controller tester, the SD card writer and card check, the Diagnostics dashboard and
backups, in Console Mode's look. Mouse, keyboard or a controller.

**Download:** `cm_win.exe` from [Releases](../../releases/latest). One file, nothing to install: put it in a
folder of its own and start it. On the SuperStation, Console Mode's app link must be on; the app finds it on
your network and pairs with the code shown on the TV.

**Updates:** the app keeps itself up to date from these releases (Settings › Updates).
